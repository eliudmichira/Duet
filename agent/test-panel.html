Test Panel Methodology

Each site is evaluated against the same pipeline the Duet Agent uses in production:

  • Detection: Can the agent find a video element? (DOM scan, shadow DOM, iframe, custom API)
  • Framework: Is the player framework recognized? (YouTube, Vimeo, Netflix, etc.)
  • Adapter: Does the agent generate a syntactically valid adapter?
  • Strategy: Which adapter template was selected? (generic, shadow_dom, cross_origin, framework_specific)
  • Confidence: Agent's self-assessed confidence (0-100) based on detection quality and challenge severity
  • Sandbox: Does the adapter pass offline validation? (syntax, required exports, common pitfalls)

Known limitations: DRM-protected sites (Netflix, Disney+, Prime) may detect video elements but cannot control playback due to Encrypted Media Extensions (EME). The agent correctly identifies these as high-severity challenges. This is a legitimate, defensible "hot take" — DOM inspection alone cannot bypass DRM. The agent's value is in automating the discovery of what can be synced (play/pause events, basic seek) even on DRM sites, rather than claiming full control.
