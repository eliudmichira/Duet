How it works

Four steps. One beat.

  1. You both install Duet

    A free Chrome extension. Takes about ten seconds.

  2. Create a room

    Send the invite link — or read out the 6-letter code.

  3. Open the same video

    YouTube, Vimeo, or any site with a normal video player.

  4. Press play

    Every pause, seek and skip happens on both screens.

Ready check

Both ready? 3, 2, 1 — play.

No more "okay… now!" over the phone. Ask once; when they're ready, both videos pause on the same frame, count down together and start at the same instant.
